# 반도체 시료 생산 관리 시스템 — 데이터 모니터링 PoC

## 개요

반도체 시료 생산 관리 시스템 콘솔 앱의 기능별 PoC 중 **데이터 모니터링** 모듈에 해당한다.  
런타임 메모리에 보유 중인 시료 DB 데이터를 콘솔에서 실시간으로 조회할 수 있는 관리자 도구를 검증한다.

## PoC 목적

| 항목 | 내용 |
|------|------|
| 검증 대상 | 인메모리 DB 레이어와 콘솔 UI 간 실시간 데이터 바인딩 |
| 입력 방식 | 콘솔 앱 '모니터링' 메뉴의 번호 입력 |
| 저장 방식 | 런타임 메모리 (파일 I/O 없음) |
| 기본 데이터 단위 | 시료 (Sample) |

## 문서 구조

```
docs/
├── data-model.md       시료 데이터 모델 정의
└── monitoring-spec.md  모니터링 기능 명세 및 메뉴 구조
```

## 기술 스택

- 언어: C++ (MSVC, Visual Studio)
- UI: 표준 콘솔 (stdout / stdin)
- 데이터 저장: STL 컨테이너 기반 인메모리 저장소

## 범위 제한

- 파일 저장/불러오기는 이번 PoC 범위 밖
- 네트워크·DB 서버 연동 없음
- 단일 프로세스, 단일 스레드 기준 (동시성 처리 미포함)
