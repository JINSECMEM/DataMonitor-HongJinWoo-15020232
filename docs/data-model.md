# 데이터 모델 — 시료 (Sample)

## 기본 단위: 시료

반도체 생산 공정에서 관리되는 최소 단위 객체다.  
모든 모니터링 조회는 이 단위를 기준으로 출력된다.

## 속성 정의

| 속성명 | 식별자 | 타입 | 단위 | 설명 |
|--------|--------|------|------|------|
| ID | `id` | `int` | — | 시료 고유 식별자, 1부터 순차 부여 |
| 이름 | `name` | `std::string` | — | 시료 명칭 (예: `SMP-001`) |
| 평균 생산시간 | `avg_production_time` | `double` | 분(min) | 해당 시료 생산에 소요된 평균 시간 |
| 수율 | `yield_rate` | `double` | % | 양품 비율 (0.0 ~ 100.0) |

## C++ 구조체 (안)

```cpp
struct Sample {
    int         id;
    std::string name;
    double      avg_production_time; // 분(min)
    double      yield_rate;          // 0.0 ~ 100.0 (%)
};
```

## 인메모리 저장소 구조

```
SampleStore
└── std::vector<Sample>   // 삽입 순서 유지, 인덱스 기반 접근
```

- 런타임 전체에 단일 인스턴스로 존재 (전역 또는 싱글턴)
- 초기 데이터는 하드코딩 더미 데이터로 프리로드
- 조회 전용 PoC이므로 삽입·삭제 API는 내부 초기화용으로만 사용

## 더미 데이터 예시

| ID | 이름 | 평균 생산시간 (min) | 수율 (%) |
|----|------|-------------------|---------|
| 1 | SMP-001 | 12.5 | 98.2 |
| 2 | SMP-002 | 15.0 | 95.7 |
| 3 | SMP-003 | 11.8 | 99.1 |
| 4 | SMP-004 | 18.3 | 87.4 |
| 5 | SMP-005 | 13.2 | 93.6 |

## 제약 조건

| 속성 | 제약 |
|------|------|
| `id` | 양의 정수, 중복 불가 |
| `name` | 비어있지 않아야 함 |
| `avg_production_time` | 0.0 초과 |
| `yield_rate` | 0.0 이상 100.0 이하 |
