# 모니터링 기능 명세

## 진입점

메인 콘솔 앱의 최상위 메뉴에서 **모니터링** 번호를 입력하면 모니터링 서브메뉴로 진입한다.

```
=== 반도체 시료 생산 관리 시스템 ===
1. 시료 관리
2. 생산 관리
3. 모니터링          <-- 이 PoC의 진입점
0. 종료
메뉴 선택: 3
```

---

## 모니터링 서브메뉴

```
=== 모니터링 ===
1. 전체 시료 목록 조회
2. 시료 상세 조회
3. 수율 기준 정렬 조회
4. 평균 생산시간 기준 정렬 조회
0. 뒤로 가기
메뉴 선택: _
```

---

## 기능별 명세

### 1. 전체 시료 목록 조회

- 인메모리 저장소의 모든 시료를 테이블 형식으로 출력한다.
- 정렬 기준: 삽입 순서(ID 오름차순)

**출력 형식**

```
--------------------------------------------------------------
 ID  | 이름       | 평균 생산시간 (min) | 수율 (%)
--------------------------------------------------------------
  1  | SMP-001   |             12.50  |    98.20
  2  | SMP-002   |             15.00  |    95.70
  ...
--------------------------------------------------------------
총 5개 시료
```

---

### 2. 시료 상세 조회

- ID를 입력받아 해당 시료의 전체 속성을 출력한다.
- 존재하지 않는 ID 입력 시 오류 메시지를 출력하고 메뉴로 복귀한다.

**입출력 흐름**

```
조회할 시료 ID 입력: 3

[시료 상세 정보]
  ID              : 3
  이름            : SMP-003
  평균 생산시간   : 11.80 min
  수율            : 99.10 %
```

**오류 케이스**

```
조회할 시료 ID 입력: 99
오류: ID 99에 해당하는 시료가 없습니다.
```

---

### 3. 수율 기준 정렬 조회

- 전체 시료를 수율 내림차순으로 정렬해 출력한다.
- 원본 저장소 순서는 변경하지 않는다 (조회 시 복사본 정렬).

**출력 형식**

```
[수율 높은 순]
--------------------------------------------------------------
 순위 | ID  | 이름       | 수율 (%)
--------------------------------------------------------------
    1 |   3  | SMP-003   |    99.10
    2 |   1  | SMP-001   |    98.20
  ...
--------------------------------------------------------------
```

---

### 4. 평균 생산시간 기준 정렬 조회

- 전체 시료를 평균 생산시간 오름차순으로 정렬해 출력한다.
- 원본 저장소 순서는 변경하지 않는다.

**출력 형식**

```
[생산시간 짧은 순]
--------------------------------------------------------------
 순위 | ID  | 이름       | 평균 생산시간 (min)
--------------------------------------------------------------
    1 |   3  | SMP-003   |             11.80
    2 |   1  | SMP-001   |             12.50
  ...
--------------------------------------------------------------
```

---

## 입력 처리 규칙

| 상황 | 처리 |
|------|------|
| 유효 메뉴 번호 | 해당 기능 실행 후 메뉴 재출력 |
| `0` 입력 | 상위 메뉴로 복귀 |
| 숫자 외 입력 | "잘못된 입력입니다." 출력 후 재입력 요청 |
| 범위 밖 숫자 | "없는 메뉴입니다." 출력 후 재입력 요청 |

---

## 흐름도

```
메인 메뉴
    │
    ▼ (번호: 3)
모니터링 서브메뉴 ──────────────────────────────────────────┐
    │                                                        │
    ├─ 1 → 전체 목록 출력 → 서브메뉴 복귀                    │
    ├─ 2 → ID 입력 → 상세 출력 → 서브메뉴 복귀               │
    ├─ 3 → 수율순 정렬 출력 → 서브메뉴 복귀                  │
    ├─ 4 → 생산시간순 정렬 출력 → 서브메뉴 복귀              │
    └─ 0 ────────────────────────────────────────────────── 메인 메뉴
```

## PoC 검증 항목

| # | 검증 항목 | 성공 기준 |
|---|-----------|-----------|
| 1 | 전체 목록 정상 출력 | 더미 데이터 5건 누락 없이 출력 |
| 2 | 상세 조회 정상 | 올바른 ID → 속성 전체 출력 |
| 3 | 상세 조회 오류 처리 | 없는 ID → 오류 메시지 출력, 앱 유지 |
| 4 | 수율 정렬 정확성 | 내림차순 정렬 결과 일치 |
| 5 | 생산시간 정렬 정확성 | 오름차순 정렬 결과 일치 |
| 6 | 원본 데이터 불변 | 정렬 조회 후 목록 순서 원상 유지 |
| 7 | 잘못된 입력 복원 | 앱 종료 없이 메뉴 재출력 |
